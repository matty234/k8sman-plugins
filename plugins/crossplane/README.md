# Crossplane

Read-only view of [Crossplane](https://www.crossplane.io).

- **Provider**: Installed, Healthy and Package columns; an alert when a
  Provider is not installed or not healthy.
- **CompositeResourceDefinition**: Established, Offered, composite and claim
  kind columns; an alert when a definition is not established.
- **Composition**: composite type, mode and number of pipeline steps, with
  the steps listed in the panel.

Permissions: reads the three kinds above. It changes nothing and runs no
commands.
